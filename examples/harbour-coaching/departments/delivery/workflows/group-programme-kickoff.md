# Group programme kickoff

## Purpose

Get a Crossroads round ready in the week before it starts, so every member arrives knowing what to expect and has done the first exercise.

## Use when

Maya says "the group starts next week", "kick off Crossroads", or it's seven days before a round's start date in `business/offers.md`.

## Load first

- `business/offers.md` (Crossroads section: dates, what's included)
- `business/voice.md`
- `departments/delivery/context.md`
- The member list Maya pastes or points to

## Steps

1. Confirm the start date, call time and member list with Maya.
2. Draft the welcome email: dates and times, Zoom link, the first exercise, what to bring to call one.
3. Draft the group-chat welcome message and three conversation starters.
4. Create a client file for each member in `departments/delivery/clients/` from the 1:1 file shape, marked "Crossroads April".
5. List the six call dates as events for Maya's own calendar.

## Check before handing over

- Every date matches the offer and the calendar.
- The first exercise takes under 20 minutes.
- Sounds like Maya: warm, plain, no exclamation marks.

## Save to

`outputs/delivery/YYYY-MM-DD-crossroads-kickoff.md` with the welcome email, chat message and calendar list.

## Needs a yes

Sending the welcome email or calendar invites to members. Adding events to Maya's own calendar is allowed (see `business/rules.md`).
